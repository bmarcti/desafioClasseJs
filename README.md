🛡️ Jornada do Herói: Simulador de Ataques
Este é um projeto simples em JavaScript que utiliza Classes e Objetos para simular heróis de diferentes tipos (mago, guerreiro, monge e ninja) e seus respectivos ataques.

🚀 Como Funciona
O sistema utiliza uma classe base chamada Heroi que armazena as propriedades do personagem e determina o tipo de ataque com base na sua classe de herói através de uma estrutura de decisão switch.

🛠️ Tecnologias Utilizadas
JavaScript (ES6+): Lógica principal e POO.

Node.js: Para execução do script no terminal.

📋 Funcionalidades
Criação de múltiplos heróis usando um constructor.

Método atacar(): Identifica o tipo do herói e retorna uma mensagem personalizada.

Exibição de detalhes: Mostra o nome e a idade de cada herói formatados.
